# Khalid Tutor

Learn The AI Agent Factory in Claude Code.

This plugin contains two parts:

- **Skill** (`skills/khalid-ai-tutor/SKILL.md`): tells Claude how to teach.
- **MCP connector** (`.mcp.json`): connects Claude to the book and your learner record.

## Install

At the prompt of a terminal session:

```
/plugin install khalid-tutor --marketplace khalidhussain-Projects/khalid-tutor
```

Answer `y` to add the marketplace, then choose a scope.

From a shell:

```
claude plugin install khalid-tutor --marketplace khalidhussain-Projects/khalid-tutor
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `khalidhussain-Projects/khalid-tutor`, then Add plugin.

## Use

Run `/mcp` and sign in to the connector the first time. Then type `/khalid-tutor:khalid-ai-tutor`.
